# # # MU SALTA # # #
Sitio web promocional e interactivo.
* **`index.html` (Inicio):** Página de presentación con una introducción al mundo de MU, clases disponibles e imágenes representativas.
* **`info.html` (Información):** Tabla detallada con los multiplicadores, experiencia, drop y características técnicas del servidor.
* **`contacto.html` (Contacto):** Formulario de registro de usuario y preferencias de juego, validado dinámicamente.
Se usó: HTML5, CSS3 Y JAVASCRIPT

Como usarlo:
1. Clona o descarga este repositorio en tu computadora.
2. Abre la carpeta del proyecto.
3. Haz doble clic en el archivo `index.html` para abrirlo en tu navegador predeterminado.
